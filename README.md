# OurList - Family Todo

A beautiful, shareable, zero-backend family todo list. Single HTML file, works offline.

## Live site (GitHub Pages)

1. Create a new repository on github.com (name it anything, e.g. `ourlist`)
2. Upload **index.html** (and this README) to the repo - drag & drop works
3. Go to **Settings > Pages**, set Source to `Deploy from a branch`, pick branch `main`, folder `/ (root)`, Save
4. Wait ~1 minute - your family gets a link like `https://YOUR-USERNAME.github.io/ourlist/`

Everyone opens the same link, adds their tasks, and hits Share to sync snapshots via URL.

## Features
- Add tasks with assignee, due date, priority
- Filter by family member or status (All / To do / Done)
- Share button encodes the whole list into a link - no server needed
- Works offline; data saved in the browser
- Double-click the logo to rename family members

Made with vanilla HTML/CSS/JS. No build step, no dependencies.
